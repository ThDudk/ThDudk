- This lets me take a peek at my friends wordle guesses, and tease them about it <:

## [UVic Course Parser](https://github.com/ThDudk/UVicCourses) — Java
- Scrapes the UVic calendar website to get course information.
- Parses html to generate a readable JSON format, and parses course requisites into a serialized tree format.
- Useful for planning ahead for your degree

## [Crown Crow - Ludum Dare 58](https://github.com/emmadilemma320/ludum_dare_) — Godot
- Game made in a team of 4 as a part of the UVic Game Development Club.
